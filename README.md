# nltk_chatbot
NLTK Chatbot

A simple rule-based chatbot built using Python and NLTK.

Requirements

Python 3

NLTK

Install:

pip install nltk

Run
python chatbot.py

About

This chatbot uses predefined rules and regular expressions to reply to user messages.

Type quit to exit.

Example
hello  
Hello  

my name is twinkle  
Hello twinkle, How are you today ?

Tech Stack

Python

NLTK

Note

This is a beginner-friendly chatbot for learning basic NLP concepts.
